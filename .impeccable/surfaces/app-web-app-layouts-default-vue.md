## Scope and mode
Refine the existing shared platform shell in Operate mode. Preserve routes, authorization, workspace switching, page content, and backend contracts. The user approved carrying People™ violet branding into a clean, compact platform UI.

## Direction contract
THESIS: A legible HRMS navigation frame that supports frequent operational work without decorative motion or nested navigation cards.
OWN-WORLD: Warm off-white and ink surfaces, violet current selection, existing People and Datlabs marks, familiar system sans and Lucide icons.
STORY: Identify the active workspace, find a permitted task, navigate quickly, and reach account controls without losing context.
FIRST VIEWPORT: A 256px desktop sidepanel, quiet 72px header, independently scrolling grouped navigation, fixed account area with dedicated sign-out, and readable content. A labelled collapse/expand button in the desktop top bar persists the optional 76px icon rail; its workspace dropdown and navigation keep accessible names. The sidebar retains only the People symbol and conditional multi-workspace controls, with static workspace copy omitted. The controls-only top bar removes breadcrumbs/titles and places profile at the right end. Violet-bordered sign-out remains dedicated. Mobile retains the brand symbol and four existing destinations with compact drawer rows and a fixed sign-out footer.
FORM: Refine the incumbent shared sidepanel/topbar composition; a local extension of established structure, so no concept seed is required. Search remains keyboard accessible and color mode resolves before its control mounts.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
